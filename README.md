<h2>⚡ Weather Greek — Hackathon Winner (🏆 3rd Place)</h2>

A mythical weather tracking dashboard inspired by the world of Greek gods. **Weather Greek** is a frontend-only project built with React, designed during a hackathon and secured **3rd place** among top innovative solutions.

This app imagines what weather would look like in the mythical lands of ancient gods, allowing users to input data manually and view visual stats for different realms.

## 🧩 Features

- ⚔️ **Thematic UI** — Ancient Greece meets modern tech  
- 🧾 **Landing Page** — Clean intro to the app  
- 📝 **Manual Data Form** — Input weather data for any fictional or real location  
- 📊 **Dashboard** — View weather details of 3 key locations:
  - 🌪️ Location Name
  - 🌍 Geographical Coordinates
  - 🌧️ Rainfall %
  - 🌤️ Weather Type
  - 📈 Weather Stats (temp, humidity, etc.)
- 🏆 **Leaderboard** — Compare weather stats in a gamified way

---

## 🎯 Tech Stack

- ⚛️ **React.js** — Component-based architecture  
- 💅 **Tailwind CSS** — Styled with thematic design elements  
- 📁 **React Router** — For smooth navigation across pages

---

## 🌐 Pages

| Page | Description |
|------|-------------|
| **Landing Page** | App intro with Greek-inspired UI |
| **Input Form**   | Enter weather data manually (location, stats) |
| **Dashboard**    | Visual overview of 3 major places |
| **Leaderboard**  | Sorts and ranks based on weather metrics |
